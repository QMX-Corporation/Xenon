## Instructions
### WHAT INSTRUCTIONS? 
* **mov: Move a Value in register.**
* **movs: 0 for all 62 Bits, 1 in 63 Bit.**
* **add: Add a Value in Register.**
* **imulp: Multiplication a Value in Register.**
* **div: Division a Value in Register.**
* **call: Executes a function/program.**
* **ret: Not executes.**
* **and all of under rest (e.g: lodsab).**
